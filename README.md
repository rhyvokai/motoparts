# MotoParts — Preloved Motorcycle Parts Marketplace

## Community Problem
In local communities, motorcycle owners often spend heavily on brand-new replacement parts or struggle to find compatible secondhand parts across cluttered general buy-and-sell chats. Many riders also have spare working parts sitting unused in their garages. **MotoParts** is a dedicated web application exclusively for motorcycle owners where anyone with an account can **sell**, **trade**, or **give away** preloved motorcycle parts—helping riders find compatible parts faster and save on repair and upgrade expenses.

## Functional Requirement (FR-01)
**FR-01:** Registered users can create or sign in to an account, post preloved motorcycle parts categorized by listing type (**Sell**, **Trade**, or **Give**) along with compatible motorcycle model, condition, and price/trade preference, browse and filter available parts, and claim/purchase a part—where claimed items immediately lock and become unclickable to prevent duplicate claims.

## How to Run
Open `index.html` directly in any modern web browser. All user accounts, preloved part listings, and claim states are stored locally in the browser using `localStorage` (no backend server required). Demo uses fictional rider names only (RA 10173).
